# 疫苗免疫

疫苗接种是赛鸽疾病预防的重要防线，尤其对于新城疫等危害严重的疫病，科学免疫能显著降低发病风险与损失。

## 常见疫苗类型

赛鸽常用的疫苗主要包括：

- **新城疫疫苗**：新城疫（鸽副黏病毒病）是赛鸽最重要的法定防控疫病之一，疫苗免疫是核心预防手段；
- **鸽痘疫苗**：预防鸽痘病毒感染，常在蚊虫高发季节前免疫；
- **其他疫苗**：根据地区流行情况与兽医建议选择性使用。

## 免疫程序

科学的免疫程序需根据赛鸽的用途、年龄、季节与流行病学情况制定：

1. **雏鸽阶段**：按免疫程序进行基础免疫；
2. **赛前加强**：比赛季前根据抗体水平决定是否加强免疫；
3. **种鸽免疫**：保证种鸽抗体水平，通过母源抗体保护雏鸽；
4. **新引进鸽**：入舍前完成隔离与必要的免疫。

## 免疫注意事项

- **疫苗质量**：使用正规渠道、冷链保存的疫苗；
- **健康状态**：仅对健康鸽接种，病弱鸽暂缓；
- **操作规范**：严格按照疫苗说明的剂量与途径接种；
- **记录完整**：做好免疫记录，便于追溯与评估；
- **兽医指导**：免疫程序应咨询专业兽医。

## 免疫与检测的关系

需要明确的是，**疫苗接种不能替代疾病监测**：

- 免疫并非 100% 有效，仍可能发生免疫失败或感染；
- 疫苗免疫可能影响某些血清学检测结果的判读；
- 分子检测（如 qPCR）可区分野毒感染与疫苗免疫；
- 定期检测有助于评估免疫效果、发现漏免个体。

## 综合防控

疫苗免疫应作为综合防控的一部分，与生物安全、环境管理、营养支持等措施配合，才能发挥最佳效果。

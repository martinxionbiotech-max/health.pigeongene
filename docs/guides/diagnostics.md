# 诊断方法

准确的诊断是有效防治的前提。赛鸽疾病诊断通常从症状观察开始，最终依赖实验室检测确认。

## 临床观察

观察赛鸽的精神、采食、呼吸、粪便与外观，是诊断的第一步，但仅凭观察不能确诊。

## 实验室检测

实验室检测是确诊的金标准。

- qPCR 核酸检测：高灵敏度、高特异性
- 血清学检测：评估免疫状态
- 病原分离：确诊参考
- 镜检：寄生虫检测

## 诊断流程

症状观察 → 初步判断 → 样本采集 → 实验室检测 → 确诊与处置。

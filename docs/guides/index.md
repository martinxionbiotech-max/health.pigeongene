# 检测与防控

本栏目汇集赛鸽健康管理的实用指南，覆盖从生物安全、疫苗免疫到实验室检测的完整防控链条。所有内容为科普参考，不构成兽医诊断建议。

## 阅读建议

- 防控是系统工程：**生物安全 → 免疫 → 监测** 缺一不可；
- 症状仅供参考，确诊依赖实验室检测（详见 [诊断方法](diagnostics.md)）；
- 涉及具体病原，请参阅 [病原百科](../diseases/index.md)。

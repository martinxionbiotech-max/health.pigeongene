# 生物安全

生物安全是通过一系列管理措施，降低病原引入与传播风险的系统性方法，是赛鸽健康管理的基础。

## 核心原则

生物安全的核心是"防患于未然"，通过阻断传播途径降低感染风险。

- 隔离：新引进赛鸽需隔离观察
- 消毒：定期对鸽舍、用具消毒
- 控制：限制人员与车辆进出
- 监测：定期检测病原

## 日常管理

保持鸽舍通风与干燥、控制饲养密度、及时清理粪便、保持饮水与饲料卫生。

## 赛前与引种

赛前进行病毒筛查，引种前对引进赛鸽进行检疫，是预防病原引入的关键环节。

## 环境监测

定期采集鸽舍地面、饮水器、食槽等环境拭子，评估环境中病原载量，弥补个体采样遗漏。

# PCR 检测

PCR（聚合酶链式反应）是赛鸽病原检测的核心技术。实时荧光定量 PCR（qPCR）以其高灵敏度与特异性，成为分子诊断的金标准。

## 什么是 PCR

PCR 通过变性、退火、延伸三个温度循环，将微量 DNA 目标片段指数级放大数百万倍，使极微量的病原核酸也能被检测到。

## 什么是 qPCR

qPCR 在 PCR 基础上加入荧光探针，实时监测扩增过程，通过 Ct 值定量分析目标核酸初始含量，灵敏度更高、特异性更强。

- 高灵敏度：检测极低拷贝数病原
- 高特异性：特异性引物探针避免交叉反应
- 定量分析：实时监测扩增过程
- 早期发现：早于症状 7-14 天检出病原

## 检测流程

样本采集 → 核酸提取 → 目标扩增 → 信号检测 → 结果判读。整个流程在严格质控下进行。

## 质控体系

专业实验室通过 MIQE 规范、内参质控、UNG 防污染系统与扩增效率监控（95%-105%），确保检测结果准确可靠。

# PCR 检测

PCR（聚合酶链式反应）是赛鸽病原检测的核心技术。其中，实时荧光定量 PCR（qPCR）以其高灵敏度与特异性，成为分子诊断的"金标准"。

## 通俗解读（打个比方）

PCR 就像一台**"DNA 复印机"**：

- 病原的核酸（DNA/RNA）在样本里可能只有极微量，肉眼根本看不见；
- PCR 通过反复"复制"，把这段目标 DNA 放大数百万倍，直到仪器能轻松检测到；
- qPCR 则更进一步，在"复印"的同时实时"计数"，还能算出原始病原有多少。

这样一来，极微量的病原也无所遁形。

## 什么是 PCR

PCR 通过**变性、退火、延伸**三个温度循环，将微量的 DNA 目标片段指数级放大数百万倍：

1. **变性**：高温打开 DNA 双链；
2. **退火**：引物与目标序列结合；
3. **延伸**：DNA 聚合酶复制出新的片段。

每循环一次，目标片段数量翻倍，经过数十个循环即可放大数百万倍。

## 什么是 qPCR

qPCR 在 PCR 基础上加入**荧光探针**，实时监测扩增过程，通过 Ct 值定量分析目标核酸的初始含量，灵敏度更高、特异性更强：

- **高灵敏度**：能检测极低拷贝数的病原；
- **高特异性**：特异性引物探针避免交叉反应；
- **定量分析**：实时监测扩增过程，可判断病原载量；
- **早期发现**：可早于临床症状 7–14 天检出病原。

## 检测流程

```
样本采集 → 核酸提取 → 目标扩增 → 信号检测 → 结果判读
```

整个流程在严格质控下进行，每一步都影响最终结果的准确性。

## 质控体系

专业实验室通过以下措施确保结果准确可靠：

- **MIQE 规范**：分子检测实验的标准化操作规范；
- **内参质控**：监控核酸提取与扩增效率；
- **UNG 防污染系统**：防止扩增产物污染导致假阳性；
- **扩增效率监控**：保持在 95%–105% 之间。

## 关键要点

- PCR 通过温度循环将微量 DNA 指数级放大数百万倍；
- qPCR 加荧光探针实时定量，灵敏度和特异性更高；
- qPCR 可早于症状 7–14 天检出病原，是分子诊断金标准；
- 严格质控（MIQE、内参、UNG、效率监控）保障结果准确。

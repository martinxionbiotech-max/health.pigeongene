# Racing Pigeon Testing and Prevention

This section gathers practical guides to racing pigeon health management, covering the whole chain from biosecurity and vaccination through to laboratory testing. All content is educational reference only and does not constitute veterinary advice.

## Reading suggestions

- Prevention and control is a system: **biosecurity → immunity → monitoring** — none of the three can be left out;
- Signs are a reference only; confirmation depends on laboratory testing (see [Diagnostic methods](diagnostics.md));
- For individual pathogens, see the [pathogen encyclopedia](../diseases/index.md).

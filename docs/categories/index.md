# 病原分类

赛鸽病原按类别可分为病毒、细菌与寄生虫（原虫）三大类。本页提供分类导航。

## 病原分类

- [病毒检测](viruses.md) — 7 种赛鸽常见病毒的传播、症状、诊断与防控；
- [细菌检测](bacteria.md) — 沙门氏菌、鹦鹉热衣原体、支原体的传播、症状、诊断与防控；
- [寄生虫检测](parasites.md) — 鸽毛滴虫的传播、症状、诊断与防控。

## 为什么分类很重要

- **用药不同**：抗病毒药、抗生素与抗寄生虫药的适用对象完全不同；
- **防控策略不同**：病毒重在免疫与生物安全，细菌重在卫生与规范用药，寄生虫重在饮水管理与驱虫；
- **检测方法不同**：不同病原对应不同的检测手段（PCR / 培养 / 镜检）。

## 检测提示

- 症状重叠时，建议多病原联合检测；
- 确诊后再用药，避免盲目用药与耐药；
- 引种检疫是防止新病原引入的第一道关口。

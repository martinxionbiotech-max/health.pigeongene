# 病毒检测

病毒是赛鸽疾病的重要病原。本页汇总 7 种赛鸽常见病毒的检测与防控知识，每个病原页均含传播途径、症状、鉴别诊断与预防要点。

## 病毒性疾病的共同特点

- **症状重叠**：呼吸道、消化道与神经症状在多种病毒病间高度相似，症状不能单独用于确诊；
- **应激诱发**：集鸽、运输、换羽等应激场景常是病毒病的触发点；
- **免疫相关**：圆环病毒等造成的免疫抑制会为其他病原打开大门；
- **检测确诊**：实时荧光 PCR/RT-PCR 是确诊的主要手段。

## 防控原则

- 疫苗免疫（新城疫等）与抗体监测；
- 生物安全：隔离、消毒、控制密度、减少应激；
- 引种检疫与定期监测，阻断隐性带毒传播。

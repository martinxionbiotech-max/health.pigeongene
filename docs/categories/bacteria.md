# 细菌检测

细菌是赛鸽疾病的重要病原类别。本页汇总 3 类赛鸽常见细菌性病原的检测与防控知识。

## 病原一览

| 病原 | 英文 | 检测方法 |
|---|---|---|
| [沙门氏菌](../diseases/shamen-shijun.md) | Salmonella spp. | 实时荧光 PCR / 细菌培养 |
| [鹦鹉热衣原体](../diseases/yingwure-yiyuanti.md) | Chlamydia psittaci | 实时荧光 PCR |
| [支原体](../diseases/zhiyuanti.md) | Mycoplasma spp. | 实时荧光 PCR |

## 细菌性疾病的共同特点

- **人兽共患需警惕**：沙门氏菌与鹦鹉热衣原体均可感染人，接触病鸽后务必洗手消毒；
- **慢性化倾向**：支原体等易转为慢性感染，反复发作；
- **药敏指导用药**：不规范使用抗生素会诱导耐药，建议在检测与药敏指导下用药；
- **环境传播**：污染饲料、饮水、粉尘是主要传播媒介。

## 防控原则

- 灭鼠防鸟、保障饲料饮水卫生；
- 湿式清扫减少扬尘（衣原体经粉尘传播）；
- 引种检疫，淘汰持续排菌个体；
- 规范用药：足疗程、药敏指导，避免滥用。

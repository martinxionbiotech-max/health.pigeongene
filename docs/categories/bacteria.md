# 细菌检测

细菌性病原是赛鸽疾病的重要来源之一。本页汇总赛鸽常见细菌与衣原体病原的检测与防控知识。

## 通俗解读（打个比方）

细菌就像**会"自行繁殖"的微小入侵者**——只要环境合适（潮湿、拥挤、卫生差），它们就能快速大量繁殖，让鸽子发病。与病毒不同，许多细菌感染可以通过抗生素治疗，但**盲目用药会催生耐药性**，所以"先检测、再用药"才是科学做法。

## 为什么细菌检测很重要

- 细菌感染种类多、症状易混淆，需检测明确病原；
- 不同细菌对抗生素的敏感性不同，检测可指导精准用药；
- 盲目用药会诱导耐药性，让后续治疗更困难；
- 检测能区分细菌与病毒、寄生虫感染，避免误诊。

## 赛鸽常见细菌性病原

| 病原 | 英文 | 检测方法 |
|---|---|---|
| [沙门氏菌](../diseases/shamen-shijun.md) | Salmonella spp. | 实时荧光 PCR / 细菌培养 |
| [鹦鹉热衣原体](../diseases/yingwure-yiyuanti.md) | Chlamydia psittaci | 实时荧光 PCR |
| [支原体](../diseases/zhiyuanti.md) | Mycoplasma spp. | 实时荧光 PCR |

- **沙门氏菌**：可引起腹泻、消瘦、关节肿胀，幼鸽危害尤重；
- **鹦鹉热衣原体**：人兽共患病原，可引起呼吸道与全身症状；
- **支原体**：常引起慢性呼吸道病，易与病毒、细菌混合感染。

## 检测方法说明

- **实时荧光 PCR**：快速、高灵敏度，是分子检测的主力手段；
- **细菌培养**：可分离活菌并做药敏试验，指导精准用药，但耗时较长。

## 关键要点

- 细菌感染需检测明确病原，再针对性用药；
- 沙门氏菌、鹦鹉热衣原体、支原体是赛鸽常见细菌性病原；
- PCR 快速灵敏，细菌培养可做药敏指导用药；
- 盲目用药催生耐药性，"先检测、再用药"更科学。

# 赛鸽健康知识库

赛鸽健康知识库（health.pigeongene.com）是 PigeonGene 数字生态的健康支撑站，为鸽友提供**科学、审慎**的赛鸽疾病与检测知识。

## 本站内容

- **12 种病原百科**：病毒、细菌、寄生虫三大类
- **PCR 检测技术**：qPCR 金标准、检测流程与质控
- **生物安全与防控**：隔离、消毒、监测
- **症状索引**：识别异常，但症状**不等于**诊断

## 科学声明

> **症状不能等同于疾病诊断**。出现可疑症状时，应通过实验室检测（实时荧光 PCR）确认病原，而非仅凭症状用药。

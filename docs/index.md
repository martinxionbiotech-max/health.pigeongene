# 赛鸽健康知识库

赛鸽健康知识库（health.senopigeon.com）是 PigeonGene 数字生态的健康支撑站，为鸽友提供**科学、审慎**的赛鸽疾病与检测知识。

## 本站内容

- [病原百科](diseases/index.md)：12 种赛鸽常见病原（7 种病毒、3 种细菌、1 种真菌、1 种寄生虫），每页介绍传播途径、常见症状、鉴别诊断、检测方法与防控要点；
- [防控指南](guides/index.md)：PCR 检测、生物安全、症状识别、疾病预防、鸽舍健康、诊断方法等 8 个实用指南；
- [病原分类](categories/index.md)：病毒、细菌、寄生虫的分类意义与用药区别；
- [术语表](glossary.md)与[常见问题](faq.md)。

## 谁适合阅读

- **鸽友**：识别可疑症状、了解何时该做实验室检测；
- **鸽舍管理者**：掌握隔离、消毒、引种检疫等生物安全要点；
- **兽医与研究者**：快速查阅病原特征与检测方法。

## 科学声明

> **症状不能等同于疾病诊断**。出现可疑症状时，应通过实验室检测（实时荧光 PCR）确认病原，而非仅凭症状用药。本站内容仅供科普参考，不构成兽医诊断建议。

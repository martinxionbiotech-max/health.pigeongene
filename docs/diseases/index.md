# 病原百科

本站收录 12 种赛鸽常见病原的百科条目，覆盖病毒、细菌、真菌与寄生虫四大类别。每个病原页均介绍传播途径、常见症状、鉴别诊断、检测方法与防控要点。

## 使用建议

- **症状相似、病因不同**：呼吸道、消化道症状在多类病原间高度重叠，用药前先检测；
- **鉴别是关键**：口腔白斑可能是毛滴虫、念珠菌或鸽痘黏膜型，治疗方案完全不同；
- **人兽共患警惕**：沙门氏菌与鹦鹉热衣原体可感染人，接触病鸽后务必洗手消毒。

> **科学声明**：症状不能单独用于确诊，实验室检测（qPCR 等）才是确诊依据。本站内容为科普参考，不构成兽医诊断建议。
